# Recall

[English](README.md)

**面向 Mac 知识工作者的本地优先工作经历账本。每一次记录都由你明确触发。**

Recall 用来看清昨天做到哪里、今天先接哪一件，以及答案出自哪条记录。哪个瞬间值得留下，由你决定。记录留在这台 Mac 上。

它保存的是你选择记下的工作经历：不同于 Limitless、Microsoft Recall 那类默认一直录屏的产品，也不同于通用的第二大脑笔记应用。

应用界面是简体中文。

## 快速开始

Recall 以源代码发布。没有已签名的下载包，也没有 App Store 上架。请在自己的 Mac 上构建。

需要 macOS 14 或更高版本，以及 Swift 6。运行和调试应用请安装完整 Xcode。只编译核心并运行离线验证器时，Xcode Command Line Tools 即可。

```bash
git clone https://github.com/samz406/Recall.git
cd Recall
swift build --jobs 1
./scripts/run-app.sh
```

脚本会构建 Recall 并打开开发用的 `Recall.app`。请用这个应用启动。本地通知只从该应用包发出。

第一次保存截图前，在 **系统设置 → 隐私与安全性 → 屏幕与系统音频录制** 中允许 Recall。只有在你记录一个瞬间，或某个已启用的事件模板触发时，Recall 才会请求屏幕内容。创建第一条提醒时，macOS 才会询问通知权限。

## 核心循环

第一周只需要做三件事。

### 记录此刻

在菜单栏选择 **记录此刻**。这一下会保存当前窗口的一条记录：一张截图，再由本机 OCR（Apple Vision）识别中文和英文。时间、来源应用、文字和原图写入 `~/Library/Application Support/Recall/`。同一菜单可以暂停屏幕采集。

在 **记录管理** 里可以把这条规则改成当前显示器，或改成仅文本（不截图）。其他模板也在那里。在其他应用里按 Enter 触发记录默认关闭，需要你明确打开。

### 每日回顾

打开 **每日回顾**，为选定的一天生成回顾，默认是昨天。回顾只读取已经保存的记录，不会再截一张屏幕。材料足以支持时，出现三个栏目：

- **今天推进了什么**
- **接下来要处理**
- **值得留意**

没有可靠内容的栏目保持隐藏。正式回顾需要你自己配置的模型连接，并允许发送脱敏文本。无论是否连接模型，已保存的记录都在 **时间线** 里。

### 问一问

打开 **问一问**。回答会标出来源，你可以打开对应的本地记录。关闭云端文本时，Recall 在本机检索并给出可追溯的摘要，不发起网络请求。打开云端文本后，请求只带上当前问题、检索到的文本片段、滚动摘要和最近一段会话，发送前会做基础脱敏。截图文件留在本机。

## 隐私摘要

- **本地优先。** 截图、OCR、SQLite 索引和对话记录都在 `~/Library/Application Support/Recall/`。搜索和存储可以离线进行。你可以暂停采集、关闭原图保存，或按 Bundle ID 排除应用。
- **明确触发。** 记录从你触发的那一下开始。连续截图、定时截图、录音和自动采集消息都保持关闭。其他应用里的 Enter 键记录默认关闭，可以暂停，且 Recall 处于前台时不响应。
- **可删除、可追溯。** 删除一条记录后，可在 **最近删除** 中保留 7 天并恢复，也可以清空本地记忆。依赖被删记录的回顾和提醒会一并移除。回答保留来源。
- **云端默认关闭。** 你可以连接兼容 OpenAI 或兼容 Anthropic 的接口并自备密钥，也可以一直关闭云端文本。密钥以普通文本写在本机 `recall-state.json`，不进钥匙串，不写进日志，也不会提交到这个仓库。提醒只有在你确认之后才会安排。Recall 不会替你发消息、建日历或改文件。

完整边界见 [隐私设计](docs/PRIVACY.md)。
