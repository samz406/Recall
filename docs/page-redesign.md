# 页面调整验收

本次按照页面优化文档的十张示意图调整原生 SwiftUI 页面，沿用现有纸色和森林绿，并使用真实档案提供列表、状态、数量和来源。

| 页面 | 调整 | 保留的操作 |
| --- | --- | --- |
| 导航 | 回看、行动、管理分组，浅绿选中，搜索和任务带文字 | 全部页面、全局搜索、任务历史及返回 |
| 每日回顾 | 左日期和主题关键词，右摘要、进展、其他、待处理，保存状态缩为小字 | 指定日期生成、重试、取消、版本、反馈、管理和删除 |
| 记忆主题 | 标签筛选与搜索对齐，摘要两行，彩色状态，只突出接着问 | 完整小结、脉络、补充、重新生成、合并、别名和更正 |
| 周期回顾 | 左保存列表，右详情，新建配置按需打开，橙色待更新状态 | 全部模板、日期范围、定时、编辑、复制导出、删除和反馈 |
| 记录管理 | 左规则和独立开关，右配置，顶部保留周期和监听状态 | 采集范围、周期、白名单、会话和提醒参与、权限检查 |
| 提醒 | 带真实数量的页签，居中空态和明确操作，检查信息降为页脚 | 发现、新建、确认、完成、推迟、忽略、历史和分页 |
| 长期记忆空态 | 输入和示例位于中央，未保存示例不进入档案 | 编辑范围和有效期的完整表单 |
| 长期记忆列表 | 分类数量、总开关、横条内容、来源日期、单条开关 | 纠正、删除关联记录、查看来源、别名、历史和整理详情 |
| 时间线 | 单行筛选、纵向日期数量条、按小时分组、来源图标、重复数量 | 精简详细、全部日期搜索、详情侧栏、多选删除、撤销 |
| 设置与问一问 | 设置单列分类和隐私状态；聊天窄阅读区、紧凑气泡和输入、来源与停止 | 模型配置、权限、全部原有设置、最近删除、会话命令 |

示意图里“失效旧回顾仍可预览”与删除后的派生内容清理冲突，因此继续清除失效正文，仅保留日期、名称和更新入口。模型连接只标记“已配置”，未测试的连接不会声称“已连通”。待办只显示已有明确行动，不因新版布局生成明日任务。

验证使用合成数据覆盖设置兼容、总开关与逐条开关持久化、日期和主题范围隔离、问答范围、反馈、清空会话、删除撤销。原生页面渲染覆盖宽窗口、小窗口和深色外观；屏幕录制权限、真实聊天采集、系统通知和本机完整操作需人工验证。
