## 关键行为核对

### 凭据、迁移与启动

- 新配置 encoder 不再写 apiKey。公开状态只有 connectionID、凭据引用和无秘密的 credentialRevision。
- Ask、每日/周期回顾、理解记录、反馈、手动提醒分析与 CLI 的生产模型入口统一通过凭据工厂。验证器使用内存凭据替身，不碰真实 Keychain。
- 密钥替换先写独立候选引用，再提交状态文件；文件保存和候选清理同时失败时仍使用原凭据，不会将新服务的 Key 误绑定给旧连接。候选项清理失败可能留下未被引用的本机钥匙串项目，不能宣称所有故障都完成安全擦除。
- 空 Key 编辑保留原凭据；替换/删除递增版本，旧请求与检查点不能继续采用旧连接。模型服务的协议、主机或端口变化时必须重新输入凭据；服务 URL 不允许夹带用户信息、查询参数或 fragment。
- 旧文件先写 Keychain 并读取确认，再原子移除明文。失败保留唯一原件，不静默回到明文请求；可重试。应用管理的旧备份单独清理，不宣称清除了用户副本、Time Machine 或磁盘历史。
- 本次采用 macOS login Keychain / SecItem，不启用 iCloud 同步。计划中的 data protection Keychain 与正式签名、provisioning、helper 身份相关，因本轮排除打包，未宣称完成此类签名兼容验证。
- 大型旧备份的解析清理在已保存页面首屏显示后执行。迁移失败不会在后台无限重复尝试钥匙串授权。
- CLI 不带 --apply 时直接只读解码档案，不创建可写 store、不迁移凭据、不读 Keychain、不调用模型。执行模型任务时使用本机钥匙串授权，不保证不同签名的裸 CLI 能自动读取正式 App 的凭据。
- schemaVersion 为 2。旧程序不认识 planned 等新状态，不能承诺无损降级；降级可能需要重新配置连接。本地账本并没有因为 Keychain 而变成整库加密。

### 行动、角色与语言

- 加入今天表示用户接受行动，不等于到期或通知。保存年月日和 IANA 时区；旧计划进入此前安排，不自动标逾期。
- 重复点击幂等；撤销仅作用于未被后续修改的接受操作。删除依据时撤回未确认候选；用户已接受的行动保留意图，删除失效来源与证明。
- 外部纪要为 importedText。即使写了“我会……”或伪造聊天角色标记，也不会自动成为本人承诺。原作者、原始时间、导入时间分别保存，来源详情可查看导入属性。
- 身份只作用于准确的应用、窗口和已确认作者；绑定不是账户认证。归属作为独立结构化元数据进入来源版本，撤销或改绑同时使旧理解、回顾及在途结果失效。
- 不替换原 OCR 的角色字词来伪造逐字引用。模型收到的角色元数据与原文分开。
- 新生成标题、概览、说明遵循输出语言；结构化字段、ID 和原文引用不翻译。切换语言不重写历史回顾。
- 文案采用编译进 Swift 的唯一键映射，未采用 String Catalog，避免引入发行包资源依赖。核心流程已英文化，少数高级诊断、历史生成内容和用户原文可保留原语言。

### 导出、会议与 MCP

- Ask 来源按回答级列出，不声称逐句核验。没有不可变来源版本的旧回答仍可阅读、普通复制，但需重新回答后再导出带来源内容。
- 导出面板结束后再次检查会话、版本、删除及排除状态。清空会话后不再导出旧回答。recall://capture/UUID 仅为本机跳转，拒绝额外路径、参数和 fragment，不是公开分享链接。
- 热键保存提示在完成取图后显示，下一次采集前隐藏旧提示；提供撤销，不激活 Recall。录入快捷键时注销热键，结束录入或唤醒后重新注册。
- 会议只在点击开始和结束时各保存一帧，相同内容也保留。忘记结束不会自动补拍。纪要导入上限 250 KB，UTF-8 txt/md，编辑器预览后保存；不接麦克风、会议机器人或外部账号。
- 会议截图与纪要可整组移到最近删除，并恢复分组。复用 7 天到期规则。
- MCP 只有 search_records、get_record_excerpt、get_daily_review；没有 HTTP 监听、写入、截图或凭据工具，数量与长度受限。
- 每个 MCP 请求重新读取当前档案，校验日期、应用、删除、排除与来源版本；回顾依据不完整或旧版本无证明时拒绝读取。日志仅记时间和工具名，不记查询、正文、token。
- 客户端名称只是标签，token 才是访问能力；不承诺验证本机程序身份，也不防御同一系统用户直接读取自己的文件。Agent 可能把文字发给它的模型；复制或导出的副本不受 Recall 撤销控制。
- 没有新增内容遥测或训练数据收集；外部模型的留存、训练政策依提供方与账号条款，不能承诺通用第三方 training opt-out。

## 本轮修正的回归问题

- 空 Key 保存意外清除凭据、更换模型后复用旧检查点、旧测试使用保存前凭据版本。
- 英文完整行动被原来只识别中文动作形态的显示检查误删。
- 字典重复键可能导致启动崩溃；运行时字段、状态、数量和设置导航漏翻。
- 导出残留 file:// 或本机路径、清空会话后仍可导出、旧无版本回答被错误认证。
- 身份撤销后来源版本不变；用改写角色标记代替独立归属元数据。
- 热键改键时仍触发、唤醒不重注册、保存提示遮挡下一次截图。
- 旧备份清理挤占首屏；CLI 预览意外进入凭据迁移。
