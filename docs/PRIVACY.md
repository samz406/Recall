# Recall 隐私与数据边界

更新：2026-11-02。英文说明见 [PRIVACY.en.md](PRIVACY.en.md)。

Recall 默认本地保存、明确触发、不录音、不连续截屏。用户主动开启的 Enter 规则和自动文字整理是独立选项，默认关闭；组合热键不会启用键盘监听。

## 采集与权限

- 记录前先检查暂停、应用排除与规则白名单，再取得像素；保存前重新检查最新设置。
- 屏幕记录使用 macOS ScreenCaptureKit，OCR 使用本地 Vision。目标限定为触发时的应用/窗口或其显示器；窗口消失不回退去截另一个应用。
- 屏幕权限在实际请求截图时使用。单次截图不采集音频，即使系统权限名称包含“系统音频”。
- 裸 Enter 监听单独需要 Input Monitoring 与 Accessibility，默认关闭、可暂停，在 Recall 前台时不触发。
- 用户自行输入的记录与导入纪要分开保存。粘贴别人的纪要不构成本人发言，聊天身份需在对应应用与窗口明确确认，可撤销。

## 本机存储

记录、可选原截图、OCR、索引、会话、回顾和用户偏好保存在 Application Support/Recall。原文与规范化角色分开，来源与修订版本可核对。原截图与文字按现有保留设置处理。

主题卡片的“完成”只在本地保存带主题与来源标识的状态更正，可从“更正记录”撤销；不改写截图文字、不删除每日回顾，也不触发模型请求、通知或新增权限。

模型 API Key 由系统 Keychain 保存。状态、导出、诊断与新备份不编码 Key；兼容旧配置的明文字段只用于迁移，成功后从状态和应用管理的旧备份中移除。迁移失败保持原磁盘文件不变，本地档案暂为只读，设置提供重试；不会静默退回明文运行。用户另存副本、Time Machine 与磁盘历史不承诺由应用安全擦除。

当前使用 macOS login Keychain 的 SecItem 接口，以兼容源码开发启动与 CLI；不启用 iCloud 同步，不新建共享访问组。系统可能要求用户允许访问。Keychain 保护密钥，不表示截图和整个本地账本已被应用端加密。

## 模型与网络

默认不允许模型文本外发。用户连接模型并允许后，以下功能可使用配置的服务：

| 功能 | 可能发送 |
|---|---|
| Ask | 当前问题、必要检索片段、受预算约束的会话上下文 |
| 每日/周期回顾 | 所选日期范围的必要脱敏材料；容量恢复/修复可能多次请求 |
| 采集后理解 | 用户另行启用时，增量整理已保存的脱敏文字 |
| 纠正反馈 | 允许后台处理时提交的纠正和必要依据 |
| 手动发现待办 | 用户启动的原文深查；每日回顾到待确认的投影本身完全本地 |
| 连接测试 | 最小连接请求，不发本地记忆 |

截图不作为这些文字请求的模型输入。Key 仅作为认证凭据发送给用户指定的 API 服务，不放进提示词或诊断。改变服务主机需要重新输入相应 Key，防止原服务凭据被顺手发送到另一个主机。

脱敏是额外保护，不是保证发现所有敏感内容。服务商的数据留存/训练政策取决于用户选择的提供方与账号；Recall 不提供能替所有第三方保证 training opt-out 的开关。不收集用于自营模型训练的内容，不新增远程使用遥测。

## 行动、删除与导出

- 模型只能提出待确认行动。“加入今天”由用户确认，不产生通知；只有用户选择时间并授予通知权限后才安排通知。
- 每日回顾“标记完成”只保存用户确认的待办状态及关联提醒状态，不请求通知权限或模型分析；完成已有重复提醒的本次行动时，沿用既有通知设置安排下一次。
- 删除来源会撤回依赖它的未确认推断。已由用户接受到今天的行动保留用户意图、移除删除来源和引用；不得再用失效依据自动完成它。
- 最近删除保留 7 天，到期不允许恢复；运行中定时清理，关闭时在下次启动清理。删除会议整组记录同时处理关联纪要，恢复可恢复分组。
- 复制/Markdown 是用户主动导出，生成前后核对来源版本；不附截图、凭据或本机文件路径。本机 recall:// 链接仅供本机定位，不是公开分享链接。
- 剪贴板工具或系统可能同步复制内容；Recall 无法收回已导出的副本。

## Agent 只读 MCP

默认关闭。用户明确选择客户端名称、日期、应用和回顾范围后可启用本机 stdio。访问令牌是能力授权；客户端名称只是匹配标签，不构成二进制身份认证。只交给信任的本机客户端，修改范围会更换令牌，撤销在下次请求立即生效。

服务仅提供有界文字搜索、片段和允许的每日回顾，无网络监听、图片/密钥接口或写工具。Agent 得到文字后可能交给其模型；“只读”不意味着不会外发。每次请求读取当前状态，删除和排除即时生效。访问日志最多约 32 KB，只含时间与工具名，不记查询、内容、标题或令牌。

## 样例与诊断

样例是独立的内存合成资料与预置结果，不调用模型，不创建真实提醒，不参与个人检索、长期记忆或统计。诊断日志仅记录安全的状态、错误类别和计数；不含原文、截图和密钥。发布签名、安装包和自动更新不在本次功能开发范围。

## 保存、恢复与保留期限

应用保存一份带摘要校验的当前状态镜像，不含 API Key，也不复制截图。档案读取失败进入恢复页面，不使用空档案覆盖；用户确认恢复前隔离损坏原件。镜像只有当前版本，不等同整盘灾备。撤回内容时清理应用管理的旧备份和损坏档案；文件删除失败进入持久重试队列，在设置中显示。用户自行复制、系统备份、剪贴板、导出及已经发给服务商的数据不在本机清理范围内。

普通记录默认文字保留 90 天、截图 7 天，可在记录管理调整；详情中可以长期保留重要文字，截图仍遵循原期限，手动删除优先。云端问答在已有授权范围内新增一次有界核验；逐条保留有原文支持的结论，失败展示原文，不展示未经核对的草稿。模型与 OCR 仍可能出错。
