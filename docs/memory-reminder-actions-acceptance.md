# 记忆操作与手动提醒验收

## 本次调整

- “不再提示这一条”现在按历史经验正文的稳定指纹关闭，匹配其他主题或重新整理相同内容后也不会重复显示；兼容旧版本按主题保存的关闭记录。点击立即隐藏，保存失败会恢复并显示错误。
- 经验提示开关与关闭记录只写相关设置，不再为这类操作重建整份记忆与全文索引；写入失败回滚内存状态。
- 去掉主题卡片上的“脉络”按钮。原功能是查看主题历史、完整内容和来源，仍可从更多菜单的“查看完整主题”进入。
- 去掉设置中“外观”旁的“新”标记。
- 新建与修改提醒复用时间线的月份日历。提醒允许未来日期，时间线、回顾等原有入口仍不可选未来日期；更换日期时保留时刻。
- “补充说明”由 2–4 行提高至 4–6 行。
- 手动提醒先保存正文、日期、重复方式，再请求通知权限。成功后进入“待处理”；权限拒绝、调试宿主不可通知、系统排队失败时仍保存为“待确认”，保留说明并显示原因。
- 新建弹窗等待结果，保存失败保留弹窗与输入；保存成功自动切换标签、定位实际分页并标出新提醒，页面显示保存去向。通知已排队但最终写入失败时，撤回通知并保留原草稿。
- 提醒单条更新与学习偏好更新补充失败回滚，避免内存显示保存成功、磁盘却没有记录。
- 保留原有提醒时间偏好学习，仅在通知安排并成功保存后记录一次确认；通知失败不计为确认。

## 回归覆盖

核心回归：同一历史经验匹配多个主题、重新整理产生新事件 ID、旧关闭标记、独立经验不受影响；关闭标记与开关重启保存、重复关闭、写入失败回滚；无来源的手动提醒持久化、问一问缓存更新、状态与学习偏好原子回滚。

原生入口回归：立即隐藏与保存反馈；手动内容先于通知权限保存；通知允许、拒绝、宿主不可用、排队失败；磁盘初次失败不请求通知、最终写入失败撤回通知；有 13 条更早提醒时自动定位第三页；跨年换日期保留时刻、提醒允许未来而时间线仍截止今天。

所有夹具为合成内容，通知使用内存替身，不创建真实通知、不读取真实截图/OCR、不连接模型、不使用真实凭据。
