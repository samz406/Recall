# Recall 架构与验收说明

Recall 使用一个 Swift Package 组织原生 macOS 应用与可复用核心。界面层只负责呈现和用户发起的命令，核心层负责截图、OCR、隐私、持久化、检索、会话与提醒。这样可以让对用户数据影响最大的逻辑在无 GUI、无真实截图和无网络的条件下验证。

## 模块边界

| 模块 | 位置 | 职责 |
|---|---|---|
| 应用界面 | `Sources/RecallApp` | SwiftUI 时间线、事件规则、记录窗口、会话、提醒、隐私设置与菜单栏。 |
| 领域模型 | `Sources/RecallKit/Domain` | 事件、记录、会话、提醒、Episode、项目状态、用户记忆、洞察、反馈和工作习惯的数据模型。 |
| 采集与 OCR | `Sources/RecallKit/Capture` | ScreenCaptureKit 单次截图、Vision OCR、去重、摘要、标签和截图归档。 |
| 隐私 | `Sources/RecallKit/Privacy` | 暂停开关、Bundle ID 排除、基础文本脱敏与云端上下文最小化。 |
| 个人智能 | `Sources/RecallKit/Memory` | 本地搜索、Episode 聚合、项目状态更新、长期记忆候选、洞察、反馈学习、工作习惯和每日简报。 |
| 本地索引 | `Sources/RecallKit/Support/SQLiteIntelligenceIndex.swift` | JSON 兼容存储之外的 SQLite WAL + FTS5 可重建投影。 |
| 会话 | `Sources/RecallKit/Chat` | 本地可追溯回答与可选 OpenAI 兼容服务适配器。 |
| 提醒 | `Sources/RecallKit/Reminders` | 增量候选提取、时间/周期识别、发生级去重、反馈学习与用户确认后的本地通知闭环。 |
| 验证 | `Verification` | 无网络集成验证器，防止核心行为回归。 |

## 数据路径

用户从菜单栏、“记录此刻”窗口或明确启用的事件规则选择一个已启用事件。Enter 键触发记录是默认关闭的独立规则；仅在用户启用、Recall 不在前台、采集未暂停且 2 秒冷却期已结束时监听键盘事件，不会吞掉原始按键。`CapturePipeline` 先读取当前隐私设置，并检查暂停状态、应用排除列表、事件白名单和系统屏幕权限；通过检查后，才使用 `ScreenCaptureKit` 获取单次图像。图像经 `VisionTextRecognizer` 转录，文本经 `PrivacyEngine` 脱敏并计算内容哈希，最近的相同哈希会被拒绝作为重复记录。

记录被保存为 JSON 状态和可选 PNG 原图，并投影到本地 SQLite/FTS5 索引。每日整理会把记录归并为 Episode，再据此更新项目状态、生成个人简报以及待确认的用户记忆和习惯候选。所有推断都保留来源记录 ID；用户可以纠正洞察、确认或拒绝记忆、启用或忽略习惯，删除源记录时相应派生信息也会级联清理。

时间线搜索与会话只读取本地记录。云端模型路径必须同时满足“用户已选择兼容模型”“隐私设置显式允许云端使用”“本机 Recall 配置中存在 API Key”三个条件；该 Key 按项目所有者要求作为普通文本保存，不访问 Keychain。外发前会删除图片路径、执行文本脱敏，并只提供项目状态、已确认用户记忆和未闭环事项等最小必要上下文。截图、完整历史、候选记忆和嵌入在 OCR 中的指令不会被发送或执行。提醒发现只读取用户允许参与的已保存文本，通过内容哈希做增量分析；它只生成候选，只有用户确认且通知授权成功后才调度本地通知。确认、忽略、完成和稍后反馈保存在本地，用于调整同类候选置信度与默认时间；每日简报通知也默认关闭。

## 人工验收脚本

在完整 Xcode 环境中运行 `./scripts/run-app.sh` 后，先在系统设置授予屏幕录制权限。点击“记录此刻”，选择“手动记录此刻”，确认可以新增一条带时间和来源应用的记录；然后删除该记录，确认时间线和截图目录同步更新。若要验证 Enter 键触发记录，先在“记录事件”中明确启用该默认关闭的规则，并在系统设置中允许 Recall 监控键盘输入；在其他应用按 Enter，确认不影响原按键且仅生成一次记录。

接着，以“待办：明天下午三点半回复客户”为备注创建一条允许参与提醒的文本记录；进入“提醒”，确认后台增量发现的候选带有正确建议时间。点击“选择时间并创建”后允许通知权限，检查系统通知中心是否出现对应计划，并分别验证通知中的“完成”“1 小时后提醒”和“明天提醒”、点击通知打开提醒页、页面内修改/稍后/取消以及重复提醒的下一次调度。

最后，分别在“隐私与模型”中暂停采集、关闭原始截图保存、将当前应用 Bundle ID 加入排除列表，确认三种设置都会阻止或限制记录。若测试云端模型，使用专门的低权限测试密钥，确认未启用“允许在我提问时发送已检索的脱敏文本”时请求会被拒绝。

菜单栏窗口回归测试：关闭、隐藏和最小化 Recall 主窗口后，分别点击菜单栏中的“打开 Recall”，确认主窗口会重新创建或恢复、切到最前并获得键盘焦点。
