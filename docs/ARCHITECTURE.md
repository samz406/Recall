# Recall 架构与验收说明

Recall 使用一个 Swift Package 组织原生 macOS 应用与可复用核心。界面层只负责呈现和用户发起的命令，核心层负责截图、OCR、隐私、持久化、检索、会话与提醒。这样可以让对用户数据影响最大的逻辑在无 GUI、无真实截图和无网络的条件下验证。

## 模块边界

| 模块 | 位置 | 职责 |
|---|---|---|
| 应用界面 | `Sources/RecallApp` | SwiftUI 时间线、事件规则、记录窗口、会话、提醒、隐私设置与菜单栏。 |
| 领域模型 | `Sources/RecallKit/Domain` | 8 个事件模板、记录、会话、提醒和隐私策略的稳定数据模型。 |
| 采集与 OCR | `Sources/RecallKit/Capture` | ScreenCaptureKit 单次截图、Vision OCR、去重、摘要、标签和截图归档。 |
| 隐私 | `Sources/RecallKit/Privacy` | 暂停开关、Bundle ID 排除、基础文本脱敏与云端上下文最小化。 |
| 记忆 | `Sources/RecallKit/Memory` | 本地关键词/时间/应用过滤和相关性排序。 |
| 会话 | `Sources/RecallKit/Chat` | 本地可追溯回答与可选 OpenAI 兼容服务适配器。 |
| 提醒 | `Sources/RecallKit/Reminders` | 待办候选提取、去重、用户确认后的本地通知。 |
| 验证 | `Verification` | 无网络集成验证器，防止核心行为回归。 |

## 数据路径

用户从菜单栏或“记录此刻”窗口选择一个已启用事件。`CapturePipeline` 先读取当前隐私设置，并检查暂停状态、应用排除列表、事件白名单和系统屏幕权限；通过检查后，才使用 `ScreenCaptureKit` 获取单次图像。图像经 `VisionTextRecognizer` 转录，文本经 `PrivacyEngine` 脱敏并计算内容哈希，最近的相同哈希会被拒绝作为重复记录。

记录被保存为 JSON 状态和可选 PNG 原图。时间线搜索与会话只读取本地记录。云端模型路径必须同时满足“用户已选择兼容模型”“隐私设置显式允许云端使用”“Keychain 中存在密钥”三个条件；外发前会删除图片路径并执行文本脱敏。提醒逻辑只生成候选，只有用户确认且通知授权成功后才调度本地通知。

## 当前验证状态

| 检查项 | 自动验证 | 状态 | 说明 |
|---|---:|---:|---|
| Swift Package 构建 | `swift build --jobs 1` | 通过 | 编译 `RecallKit`、`RecallApp` 和 `RecallVerifier`。 |
| 事件模板完整性 | `RecallVerifier` | 通过 | 覆盖全部 8 个模板及默认开关。 |
| 基础隐私脱敏与应用排除 | `RecallVerifier` | 通过 | 覆盖邮箱、卡号、密码形式文本及 Bundle ID 排除。 |
| 记录管线、搜索、提醒去重、持久化、会话引用、长对话压缩 | `RecallVerifier` | 通过 | 共 8 项无网络集成检查，包含模拟截图到 OCR、脱敏、截图保存、重复记录拦截和滚动摘要窗口。 |
| 原生应用启动 | `open .build/.../RecallApp` | 通过 | 已在目标 Mac 上确认进程启动。 |
| 实际屏幕权限、真实截图、Vision OCR | 人工验收 | 待用户授权后执行 | 不自动截取用户桌面，以避免采集无关敏感内容。 |
| 本地通知投递 | 人工验收 | 待用户授权后执行 | 通知权限应在用户创建首个提醒时由系统请求。 |
| Anthropic 兼容模型请求 | `RecallVerifier --live-anthropic` | 通过 | 使用用户提供的 MiniMax Anthropic 兼容服务进行一次最小化真实请求；密钥未保存到代码或日志。 |

## 人工验收脚本

在完整 Xcode 环境中运行 `swift run RecallApp` 后，先在系统设置授予屏幕录制权限。点击“记录此刻”，选择“手动记录此刻”，确认可以新增一条带时间和来源应用的记录；然后删除该记录，确认时间线和截图目录同步更新。

接着，在“记录事件”中启用“待办或承诺创建”，以“待办：明天回复客户”为备注创建一条文本记录；进入“提醒”点击“从记录中检查”，确认候选出现。点击“创建提醒”后允许通知权限，检查系统通知中心是否出现对应计划。

最后，分别在“隐私与模型”中暂停采集、关闭原始截图保存、将当前应用 Bundle ID 加入排除列表，确认三种设置都会阻止或限制记录。若测试云端模型，使用专门的低权限测试密钥，确认未启用“允许在我提问时发送已检索的脱敏文本”时请求会被拒绝。
